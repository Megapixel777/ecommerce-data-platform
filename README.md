# E-Commerce Data Platform

End-to-end data engineering platform for an e-commerce business.

## Tech Stack

- Python
- PySpark
- Databricks
- Delta Lake
- Spark SQL
- Git
- GitHub
- GitHub Actions
- CI/CD
- Power BI

## Architecture

The platform follows a Medallion Architecture:

- Bronze — Raw data ingestion
- Silver — Cleaned and validated data
- Gold — Business-ready data marts
